# InsertAnything Project Website

This directory contains the static English project page for:

**InsertAnything: Generalizable Contact-Rich Precision Insertion from Simulation to Reality**

## Local preview

```powershell
python -m http.server 8765
```

Open `http://localhost:8765/` in a browser.

## GitHub Pages

The page is intentionally framework-free. It can be published from a `gh-pages`
branch or from the repository's `/docs` directory. Before publication, replace
the `(soon)` arXiv and BibTeX placeholders when the preprint is available.

The videos under `assets/video/` are high-quality copies of the source clips used
for the project presentation. The original research videos remain outside this
website directory.
